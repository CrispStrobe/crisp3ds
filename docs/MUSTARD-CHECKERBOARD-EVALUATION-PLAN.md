## Fixed matching and metrics

Match poses by exact original TRAIN JPEG stem, never by sorted index or nearest pose. The candidate set is the 39 already-detected frames; report any reference-missing names and evaluate only exact matches. Validate finite proper rotations, positive finite camera ranges, and a nondegenerate center constellation before fitting. Interpret both camera matrices as world-to-camera with OpenCV image axes and document the metadata conversion explicitly; if the supplied convention cannot be established without an arbitrary correction, mark orientation comparison unavailable rather than fitting one.

Let checkerboard-camera centers be `C_b = -R_b^T t_b` in square units and supplied-camera centers be `C_r` in their native units. Fit one **proper, positive-scale** least-squares similarity `C_r ≈ s Q C_b + u` over all matched centers (Umeyama/Kabsch, `det(Q)=+1`, `s>0`); prohibit per-frame alignment, outlier deletion, robust refitting, or a reflection. Report `s`, determinant, singular values/conditioning, matched names, and median/p95/max center residuals divided by the supplied cameras' median distance from their centroid. Also report raw residuals in supplied units. Repeat the same prespecified similarity fit leaving each matched frame out, then predict that frame's center and summarize normalized leave-one-out residuals. No reference pose may alter any image-derived pose.

With the **same center-fit rotation** `Q`, predict each supplied world-to-camera orientation as `R_pred = R_b Q^T`. Report median/p95/max geodesic angle `angle(R_r R_pred^T)` in degrees; do not fit an independent orientation offset. A global 180° checkerboard-label reversal is a world-frame gauge that a proper similarity absorbs, so do not choose the global label using reference errors. Include the 39 per-frame residuals and a count of unmatched frames for audit, but no pass/fail threshold or claim of calibrated absolute accuracy is predeclared. State the limitation: the detected cameras cover a partial arc (`NP3_006`–`NP3_288`) and the full-turn orbit gate remains unavailable at 39/60 slots.

## Distinct later recovery branch, not part of this evaluation

The frozen full-grid detector missed nine frames, including a visibly bottle-occluded board at `NP3_336`. A later *new* experiment could detect partial checkerboard line/intersection lattices and fit a robust planar homography or PnP from indexed visible corners. It would need separate code and artifacts, synthetic occlusion fixtures, a minimum unique indexed-corner count and spatial spread, explicit handling of lattice-offset/180° ambiguity, and frozen rejection thresholds **before** running on missed TRAIN frames. Neither this evaluation nor that future branch may select labels or thresholds from Berkeley camera errors. Until such a branch is reviewed and run, no pose is imputed for the missing arc.
