## Frozen track gates, before any real coordinates

Triangulate each three-or-more-posed-view track in board coordinates using normalized `cv2.undistortPoints(raw_xy,K,d)` rays and fixed `[R|t]` DLT. Reject nonfinite or out-of-frame raw/virtual coordinates, duplicate posed-view observation, infinite/unstable homogeneous point, any nonpositive camera depth, **maximum** pairwise viewing-ray parallax below **1.0°** (at least one usable baseline; not a minimum angle for every pair), or any original distorted **or** virtual ideal reprojection error above **2.0 px**. Do not robustly refit, delete high-error observations, or change poses. All counts are per whole input track with one first-failure reason.

The checkerboard itself defines the **unfitted** plane `z_board=0`; centered inner corners span `x∈[-4,4]`, `y∈[-3.5,3.5]` square units. The printed 10×9-square footprint is `|x|≤5`, `|y|≤4.5`. Determine the camera-facing normal sign solely from the 39 image-derived camera centers' board-frame z values; require all centers on the same side and median absolute z ≥5 squares, otherwise mark this gate unavailable rather than choosing a side from reference or tracks. For each triangulated point let `h = sign(median camera_center_z) × z_board`. Reject `h≤0` as on/behind the plane. Conservatively reject `0<h<1.0` square unit, counting `board_plane_footprint` if inside the printed footprint and `near_plane_outside_footprint` otherwise. Only `h≥1.0` passes this analytic board-plane exclusion, anywhere laterally; do not impose a bottle bounding box inferred from GT. This intentionally sacrifices nearby object points and **does not** eliminate turntable/support parts elevated above the band. Retained tracks remain candidate object geometry until separately validated.
